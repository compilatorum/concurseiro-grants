## Wave plan

### Wave 1 — strongest existing proof
- ValueCurator: prepare one Solana-focused technical application; do not pitch the whole portfolio.
- Farcaster Commons Lab: run a public micro-experiment with one challenge and publish the evidence trail.
- Gitcoin: separate developer-tooling and commons proposals; avoid a generic umbrella application.
- Superteam Earn: select scoped bounties that produce reusable commits and references.

### Wave 2 — open infrastructure
- Promptcraft / Compilatum: extract a module with README, tests, license, release and external onboarding.
- Lakehouse / Oracle: choose one real ecosystem integration (The Graph, Filecoin or Interchain) and prove it with a working adapter.
- Ethereum ESP: use office hours and general intake; submit only against a well-defined gap. Check wishlist/RFP status live.

### Wave 3 — impact and commercialization
- Farcaster Commons: publish outcomes and seek community funding only after a real contributor base exists.
- Hypercerts / Open Source Observer: structure impact claims and measurements; neither guarantees a grant.
- Commercial modules: convert to pilots, API/SaaS, support or licensing rather than stretching public-good grants across private development.

## Route exclusions / cautions

- Optimism Retro Funding was reported paused after Season 7 in the 2026-10-30 landscape snapshot; monitor Governance Fund missions separately.
- The former Arbitrum Questbook domain-grants program was marked complete; use current Foundation programs only.
- OpenSats is not a general AI/Web3 fund: require an authentic Bitcoin, Nostr or relevant FOSS/security contribution.
- Stellar SCF is conditional on a meaningful Stellar integration.
- Colosseum is an accelerator/hackathon/investment route, not a generic grant.
- An aggregator listing does not prove an application window is open.

## Decision rule

Qualified = Eligibility × ThesisFit × DeliverableClarity × EvidenceReadiness

If any factor is effectively zero, pause the application and improve the work package.
